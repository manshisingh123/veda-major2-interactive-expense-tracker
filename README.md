# ExpenseFlow — Interactive Expense Tracker

A responsive expense tracker developed for Veda Technology Major Project Task 3.

## Features

- Add, edit and delete expenses
- Expense categories
- Date and category filtering
- Search and sorting
- Total and monthly expense calculations
- LocalStorage persistence
- CSV export
- Responsive user interface

## Technologies

- HTML5
- CSS3
- JavaScript
- Browser LocalStorage
- Git and GitHub

## How to Run

1. Clone or download this repository.
2. Open the folder in Visual Studio Code.
3. Open `index.html` in your browser or use Live Server.
4. Add expenses and test the application.

No backend server or database is required.

## Learning Outcomes

Practiced DOM manipulation, event handling, form validation,
JavaScript arrays and objects, filtering, sorting, responsive
CSS, and browser storage.
